C

RGB channel signature — what raw channels show per failure type

'G≈GT' is the fraction of windows where the green channel's dominant spectral peak matches the true heart rate — the clearest indicator that the cardiac signal is accessible in the raw data. For correct windows this is 78.3%. For every failure type it drops to 10–38%, confirming that the G channel stops tracking the cardiac frequency before the failure occurs. 'G≈wrong' shows G is already pointing at the wrong frequency — the error is present in the raw signal before any color projection is applied. The super-harmonic 2× case is the exception: no raw channel shows the wrong frequency (G≈wrong ≈ 12%) because the 2× artefact is created by phase cancellation inside the weighted projection, not by any dominant channel frequency.
D

G-channel SNR — median + IQR per failure type

The median G-channel SNR for correct windows is 1.00; for any failure type it is ≤ 1.00 (median across all failures: 1.00). The threshold of 1.7 sits between the two distributions and can be used as a per-window quality gate. G_SNR = top1 power ÷ top2 power in the green channel PSD. A value close to 1.0 means two competing spectral peaks of equal strength — the HR extractor is essentially guessing. Error bars show the interquartile range (p25–p75); the wide IQR for 'correct' windows reflects the natural variability in signal quality across subjects and datasets.

G

G-channel SNR as a window quality gate

Windows with G_SNR < 1.7 have an error rate of 4.2%; those with G_SNR ≥ 1.7 have nan% — a nan× difference. At G_SNR ≥ 2.5 the error rate drops to nan%. Practical implication: flagging or down-weighting windows with G_SNR < 1.7 before final HR estimation would reduce reported errors for both the model and CHROM without any changes to the underlying signal processing. This is especially relevant for high-HR subjects (UBFC) where the sub-harmonic contaminates the green channel, lowering G_SNR even when the subject is otherwise cooperative.
