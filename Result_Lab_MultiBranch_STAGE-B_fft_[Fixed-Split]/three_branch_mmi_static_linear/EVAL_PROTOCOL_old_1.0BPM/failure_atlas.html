A

Error taxonomy — model vs CHROM across all 7,185 windows

Analysis over 7,185 windows from 3 datasets (PURE, TokyoTech, UBFC). The model is correct in 6,997 (97.4%) windows; CHROM in 6,854 (95.4%). Overall model MAE = 0.841 BPM; CHROM MAE = 1.320 BPM. The dominant failure for both methods is the 2-bin quantisation error (model: 0 windows, CHROM: 0 windows) caused by the FFT bin width of 7.5 BPM at the 8-second window length. Sub-harmonic failures are model-specific to a greater degree (model: 1, CHROM: 15) and super-harmonic 2× failures occur in 2 model windows.

C

RGB channel signature — what raw channels show per failure type

'G≈GT' is the fraction of windows where the green channel's dominant spectral peak matches the true heart rate — the clearest indicator that the cardiac signal is accessible in the raw data. For correct windows this is 76.8%. For every failure type it drops to 10–38%, confirming that the G channel stops tracking the cardiac frequency before the failure occurs. 'G≈wrong' shows G is already pointing at the wrong frequency — the error is present in the raw signal before any color projection is applied. The super-harmonic 2× case is the exception: no raw channel shows the wrong frequency (G≈wrong ≈ 12%) because the 2× artefact is created by phase cancellation inside the weighted projection, not by any dominant channel frequency.
D

G-channel SNR — median + IQR per failure type

The median G-channel SNR for correct windows is 1.03; for any failure type it is ≤ 1.45 (median across all failures: 1.03). The threshold of 1.7 sits between the two distributions and can be used as a per-window quality gate. G_SNR = top1 power ÷ top2 power in the green channel PSD. A value close to 1.0 means two competing spectral peaks of equal strength — the HR extractor is essentially guessing. Error bars show the interquartile range (p25–p75); the wide IQR for 'correct' windows reflects the natural variability in signal quality across subjects and datasets.

F

Case study: UBFC — 'vid_41

Subject 'vid_41 in UBFC has 60 windows total. 58 (1.6%) are correct. Model MAE = 1.49 BPM vs CHROM = 5.55 BPM. Large errors (2 windows, 0.1%): Unclassified spectral confusion — the wrong frequency dominates both the raw channels and the projected output simultaneously. Low G-SNR windows (59, 1.6%): G_SNR below 1.7 in 59 windows — the green channel's dominant frequency is not clearly the cardiac signal. These windows overlap heavily with the failure windows shown above. The longest consecutive failure run spans windows 0–1 (2 windows).
G

G-channel SNR as a window quality gate

Windows with G_SNR < 1.7 have an error rate of 2.6%; those with G_SNR ≥ 1.7 have 0.0% — a inf× difference. At G_SNR ≥ 2.5 the error rate drops to nan%. Practical implication: flagging or down-weighting windows with G_SNR < 1.7 before final HR estimation would reduce reported errors for both the model and CHROM without any changes to the underlying signal processing. This is especially relevant for high-HR subjects (UBFC) where the sub-harmonic contaminates the green channel, lowering G_SNR even when the subject is otherwise cooperative.
